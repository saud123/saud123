## 🚀 Featured AI Engineering Projects

### 01. 🦷 AI Dental Clinic & Voice Receptionist

**An AI-powered dental clinic management system with a multilingual voice receptionist.**

`Python` `FastAPI` `Next.js` `Google Gemini` `PostgreSQL` `pgvector` `ElevenLabs`

- Engineered an LLM-powered backend with custom tool calling for booking, cancelling, and rescheduling appointments.
- Built a multilingual voice pipeline integrating speech-to-text, Gemini reasoning, and text-to-speech.
- Implemented RAG-based patient memory using pgvector to retrieve patient history and summarize previous sessions.
- Developed safety guardrails to restrict non-clinical queries and prevent unauthorized medical diagnosis.

🎬 [Watch Project Demonstration](https://youtu.be/QULMX-63Avw)

### 02. 📈 Multi-Agent Financial Intelligence Platform — PSX

**An AI-powered financial intelligence platform for Pakistan Stock Exchange analysis.**

`Python` `FastAPI` `PostgreSQL` `Pinecone` `Google Gemini` `Playwright` `PyMuPDF`

- Designed a supervisor-agent architecture coordinating five specialist agents for market data, sentiment, risk, macroeconomic analysis, and RAG.
- Developed a financial document ingestion pipeline to process quarterly reports, generate embeddings, and index documents in Pinecone.
- Implemented a three-provider LLM fallback architecture using Gemini, Groq, and OpenRouter.
- Built a backtesting framework using deterministic mathematical signals to validate AI-generated recommendations.

### 03. 🏦 Explainable Loan Default Prediction & Risk Dashboard

**An end-to-end machine learning solution for loan default prediction and financial risk assessment.**

`Python` `Scikit-Learn` `Gradient Boosting` `SHAP` `Streamlit` `Pandas`

- Processed 32K+ loan records through data cleaning, imputation, and feature engineering.
- Developed a Gradient Boosting model achieving **93.4% accuracy** and **0.946 AUC-ROC**.
- Integrated SHAP to explain model predictions and identify key risk factors.
- Built an interactive Streamlit dashboard for real-time credit risk scoring.
